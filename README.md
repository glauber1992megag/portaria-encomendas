# portaria-encomendas

Sistema de gestão de encomendas para portaria com entrada, saída, registro de moradores, OCR e backup em PDF.

## Funcionalidades
- Cadastro de moradores e familiares
- Leitura de etiqueta por câmera ou galeria
- OCR com preenchimento automático
- Registro de entrada e saída da encomenda
- Relatório diário em PDF
- Armazenamento local no aparelho
- Compatível com build Android via Capacitor

## Requisitos
- Node.js 20+
- npm

## Instalação

npm install
